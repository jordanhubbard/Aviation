# Demo Scenario Scripts

## Overview
This document defines demo scenario scripts and datasets for training flights. The scenarios are designed to simulate various flight conditions and emergencies to aid in pilot training and evaluation.

## Scenarios
1. **Takeoff**
   - **Starting State**: Aircraft on runway, engines running.
   - **Triggers**: Pilot initiates takeoff sequence.
   - **Description**: This scenario simulates the takeoff process, including acceleration and lift-off.

2. **Approach**
   - **Starting State**: Aircraft in air, approaching destination.
   - **Triggers**: Pilot initiates landing sequence.
   - **Description**: This scenario covers the approach phase, focusing on descent and alignment with the runway.

3. **Emergency**
   - **Starting State**: Aircraft in air, normal flight.
   - **Triggers**: Simulated engine failure.
   - **Description**: This scenario tests the pilot's response to an engine failure, requiring quick decision-making and emergency procedures.

## Script Format
- **Title**: Name of the scenario.
- **Description**: Brief overview of the scenario.
- **Starting State**: Initial conditions for the scenario.
- **Triggers**: Events that initiate the scenario.
- **Objectives**: Key learning objectives and skills to be demonstrated.
- **Duration**: Estimated time to complete the scenario.
