# Autopilot & Flight Guidance

## Scope
Simulated autopilot with lateral/vertical modes, flight director, and envelope protection.

## Lateral Modes
- ROL (Roll Hold)
- HDG (Heading Hold)
- NAV (GPS/VOR navigation)
- APR (Approach)
- BC (Backcourse)

## Vertical Modes
- PIT (Pitch Hold)
- VS (Vertical Speed)
- ALT (Altitude Hold)
- ALTS (Altitude Select capture)
- VPTH (Vertical Path / VNAV)
- GS (Glideslope)
- GP (Glidepath)

## Additional Features
- Flight director command bars
- Autotrim
- Autopilot disconnect warnings
- Envelope protection (pitch/bank limits)
- Overspeed/stall protection
