# Data Licensing Review Summary

## Overview
This document summarizes the licensing review for navigation data, charts, and weather sources used in the Aviation monorepo.

## Data Sources and Licenses

### Navigation Data
- **Source:** OurAirports, OpenAIP
- **License:** Public Domain (OurAirports), Open Database License (ODbL) 1.0 (OpenAIP)
- **Attribution Requirements:** Must credit OurAirports and OpenAIP in any public displays of data.
- **Redistribution Restrictions:** Redistribution allowed under the terms of the ODbL license.

### Charts
- **Source:** OurAirports, OpenAIP
- **License:** Public Domain (OurAirports), Open Database License (ODbL) 1.0 (OpenAIP)
- **Attribution Requirements:** Must credit OurAirports and OpenAIP in any public displays of data.
- **Redistribution Restrictions:** Redistribution allowed under the terms of the ODbL license.

### Weather Sources
- **Source:** AviationWeather.gov, OpenWeatherMap
- **License:** Public Domain (AviationWeather.gov), Attribution-ShareAlike 4.0 International (OpenWeatherMap)
- **Attribution Requirements:** Must credit AviationWeather.gov and OpenWeatherMap in any public displays of data.
- **Redistribution Restrictions:** Redistribution allowed under the terms of the OpenWeatherMap license.

## Detailed Analysis

### Navigation Data
- **Description:** Navigation data provided by OurAirports and OpenAIP, covering airport and route information.
- **Usage Terms:** Data can be used freely for non-commercial purposes with proper attribution.

### Charts
- **Description:** Aeronautical charts provided by OurAirports and OpenAIP, including approach plates and airport diagrams.
- **Usage Terms:** Data can be used freely for non-commercial purposes with proper attribution.

### Weather Sources
- **Description:** Real-time weather data provided by AviationWeather.gov and OpenWeatherMap, including METAR and TAF reports.
- **Usage Terms:** Data can be used freely for non-commercial purposes with proper attribution.
