# Retired tracker history

[GitHub Issues](https://github.com/jordanhubbard/Aviation/issues) are the sole
tracking authority. This directory preserves migration evidence only.

- [Migration mappings](github-migration.json) link the seven formerly active records
  and the native rewrite program to GitHub. Six stale administrative records were
  reconciled against committed completion evidence and imported as closed issues.
- [Legacy task summary](legacy-task-summary.json) preserves 507 historical IDs,
  titles and states without copying private descriptions, credentials or task execution state.
- [Former roadmap](pre-github-roadmap.md) preserves authored design/evidence history.

Terminal legacy tasks remain historical records, rather than reopening hundreds of
obsolete attempts. Current status, dependencies and closure live in GitHub.
